# Contributing

Thanks for helping improve the QRavate integrations.

- **Bugs and ideas:** open an issue in the repository concerned, with the templates provided.
- **Pull requests:** welcome for fixes and small improvements. For a new action or trigger, open an issue first so we can check the API supports it.
- **Each repository** has its own README with the commands to install, test and build it. CI must pass before a pull request is merged.
- **Never commit** an API key, a webhook secret or a token, even in tests: use the mocks provided.

The integrations only use the public [QRavate API](https://www.qravate.com/docs). Questions about a QRavate account go to support@qravate.com.
