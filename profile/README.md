This organization hosts the public building blocks around the QRavate API. The QRavate service itself is not open source.

| Repository | What it is |
|---|---|
| [n8n-nodes-qravate](https://github.com/QRavate/n8n-nodes-qravate) | n8n community nodes: QR code actions and a trigger on QR code events |
| [zapier](https://github.com/QRavate/zapier) | Zapier integration: instant triggers, actions and searches |
| [make](https://github.com/QRavate/make) | Make app: modules, instant trigger and searches |
| [mcp](https://github.com/QRavate/mcp) | Remote MCP server: create and manage QR codes from Claude, ChatGPT, Cursor and other AI assistants |
| [openapi](https://github.com/QRavate/openapi) | OpenAPI 3.1 specification of the QRavate REST API |

**Need help with your QRavate account?** Write to support@qravate.com or use the [contact page](https://www.qravate.com/contact). Issues in these repositories are for the integrations themselves.
