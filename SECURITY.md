# Security policy

## Reporting a vulnerability

If you find a security problem in a QRavate integration, in the QRavate API or in the QRavate service, please **do not open a public issue**.

Report it privately, in one of these ways:

- with GitHub's **Report a vulnerability** button, in the **Security** tab of the repository concerned;
- by email to **support@qravate.com**, with "Security" in the subject.

Please include what you found, how to reproduce it and what it could allow. We will acknowledge your report within 3 business days, keep you informed while we fix it, and credit you once it is fixed if you wish.

## Scope

- The repositories of this organization: n8n nodes, Zapier and Make integrations, MCP server listing, OpenAPI specification.
- The QRavate service: `www.qravate.com`, `qravate.page`, the REST API and the MCP server.

Please only test against your own account and your own QR codes, and do not run automated scans that could degrade the service for other users.
